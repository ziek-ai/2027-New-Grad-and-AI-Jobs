# Security

Do not post credentials, candidate data, private JDs or vulnerability details in public issues. Use the repository's private vulnerability reporting feature after the owner enables it. Until then, contact Ziek privately through https://www.ziek.dev/contact.

CI is read-only. Do not add production database keys, pull_request_target execution of contributor code, automatic production imports or automatic application submission. Link validators must not fetch arbitrary contributor-controlled/internal hosts.
